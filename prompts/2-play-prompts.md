# Play prompts — pick any two

After each prompt, **refresh your browser** (⌘R on Mac / Ctrl+R on Windows) to see the change.

## 🎨 Make it yours
```text
Give the dashboard our company colors (dark navy and bright green) and rename it "Revenue Command Center".
```

## 🔎 Make it useful
```text
Add a search box that filters deals by company name, and let me sort the table by deal value by clicking the column header.
```

## 🚩 Add a business rule
```text
Let me flag any deal as "Needs attention" with one click, highlight flagged rows in red, and add a filter to show only flagged deals.
```

## 📊 Add a chart
```text
Add a simple bar chart showing total pipeline value per stage. Draw it with plain HTML/CSS or canvas — no external libraries.
```

## 🎉 Make it fun
```text
When I change a deal's stage to "Closed Won", show a short confetti celebration and a message like "Deal closed! 🎉".
```

## 🎯 Forecast
```text
Add a "Weighted forecast" card that multiplies each deal value by a probability per stage (Prospecting 10%, Qualified 30%, Proposal 50%, Negotiation 75%, Closed Won 100%) and shows the total.
```

## 💾 Remember my changes
```text
Save any deals I add or change in the browser's local storage so they're still there after I refresh. Add a "Reset demo data" button.
```

## 🕵️ Be the tester
```text
Review the dashboard like a QA tester. Check the filters, totals, and the add-deal form for bugs or confusing behavior, fix anything you find, and tell me in plain English what you changed.
```

## ✍️ Your own idea
Just describe it in normal words. Examples:
- "Make it look good on my phone."
- "Add a dark mode toggle."
- "Show which deals close this month."
