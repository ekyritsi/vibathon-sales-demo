# Starter prompt

Copy everything inside the box and paste it into the GitHub Copilot app.

```text
Build a simple, attractive Sales Deal Dashboard in a single self-contained index.html file, using HTML, CSS, and JavaScript. No frameworks, package installs, external services, or build tools. It must work when opened directly in a browser.

Include 8 fictional sales opportunities with company name, deal value, stage, close date, and next action. Show total pipeline value, deal count, and average deal size. Add a stage filter and a button to add a fictional opportunity. Use sample data only.

Make it easy for a nontechnical person to use, with clear labels and a polished layout. Do not initialize Git or require a repository. Save the file in the current folder and tell me exactly where it is and how to open it by double-clicking — no terminal commands.
```

When Copilot is done, open the file it created (`index.html`) by double-clicking it — it opens in your browser.
