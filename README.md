## The challenge

> *"Can a sales leader turn an idea into a working tool in 15 minutes — without writing a line of code?"*

Everyone builds the same **Sales Deal Dashboard** (fictional data, one HTML file, opens in the browser), then makes it their own.

## Ground rules

- ✅ Fictional data only — **never** paste real customer or deal data
- ✅ One file (`index.html`), opened by double-clicking — no installs, no Git, no terminal
- ✅ Describe *what you want*, look at the result, ask for changes
- ❌ No CRM connections, databases, or deployment
